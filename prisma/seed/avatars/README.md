# عکس‌های پروفایل داده‌ی تست

هر عکسی که اینجا با اسم `<username>.jpg` بگذاری (یا `.png` / `.webp`)، `npm run db:seed`
آن را عکس پروفایل همان کاربر می‌کند؛ مثل آپلود معمولی، تا ۱۰۲۴ پیکسل کوچک و بدون
اطلاعات اضافه (مثل موقعیت مکانی) ذخیره می‌شود. عکس‌های این پوشه به git نمی‌روند.
